## Codebase Patterns
- libs.versions.toml is the single source of truth for all dependency versions — never hardcode versions in build.gradle.kts files
- wear/build.gradle.kts already has play-services-wearable, retrofit2, retrofit2-converter-gson, kotlinx-coroutines-android, and kotlinx-coroutines-play-services
- Both modules share applicationId com.pl.pulselab and minSdk 30 — avoid any API below 30
- Use the wear module's build.gradle.kts as the reference for what dependencies are available
- HomeScreen follows the stateful/stateless split: HomeScreen(viewModel) wraps HomeScreenContent(uiState, onStart, onStop)
- HomeUiState is a sealed class: Idle, Monitoring(bpm, hrv, spo2, stressIndex, sessionId, readingsSent), Error(message)
- WearDataSender.send() currently returns Unit and catches all exceptions silently with Log.e()
- Icons in wear module: add `implementation(libs.androidx.compose.material.icons.extended)` to wear/build.gradle.kts, then import `androidx.compose.material.icons.Icons` and `androidx.compose.material.icons.filled.*`
