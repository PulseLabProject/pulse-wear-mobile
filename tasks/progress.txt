## Codebase Patterns
- libs.versions.toml is the single source of truth for all dependency versions — never hardcode versions in build.gradle.kts files
- wear/build.gradle.kts already has play-services-wearable, retrofit2, retrofit2-converter-gson, and kotlinx-coroutines-android; mirror these in app/build.gradle.kts as needed
- Both modules share applicationId com.pl.pulselab and minSdk 30 — avoid any API below 30
- Use the wear module's build.gradle.kts as the reference for what dependencies are available
