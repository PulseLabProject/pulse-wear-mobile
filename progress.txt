## Codebase Patterns
- Clerk SDK package is `com.clerk.api` (not `com.clerk.android`) — artifact `com.clerk:clerk-android-api`
- Clerk.initialize is called on the singleton INSTANCE: `Clerk.initialize(context, publishableKey)`
- JAVA_HOME must be set to `/opt/android-studio/jbr` to run Gradle on this machine
- local.properties is the right place for secrets (CLERK_PUBLISHABLE_KEY); already gitignored
- Build requires `import java.util.Properties` at top of build.gradle.kts when reading local.properties
- libs.versions.toml alias for `clerk-android-api` resolves to `libs.clerk.android.api` (dots → hyphens in alias name)
